## Featured Projects

### 1. CyberGuard AI – AI-Assisted Cybersecurity Analysis

CyberGuard AI is a cybersecurity analysis application that uses Google's Gemini API to evaluate security scenarios and provide potential threat classifications, severity levels, and recommended investigation steps.

**Technologies:**
- Python
- Streamlit
- Google Gemini API

**Project Files:** `ai-assistant/`

### 2. CSRF Attack Simulation – SEED Cybersecurity Lab

This project explores Cross-Site Request Forgery (CSRF) vulnerabilities in a controlled cybersecurity laboratory environment. It demonstrates how forged requests can exploit web application behavior and examines the role of CSRF tokens in preventing attacks.

**Technologies:**
- Linux
- Web Security
- CSRF Testing

**GitHub Repository:** https://github.com/ArletteT3/csrf-attack-simulation-seed-lab

### 3. PIN Security Simulator

A Java-based project that demonstrates PIN security concepts and password-related logic through a simulated application.

**Technologies:**
- Java
- Object-Oriented Programming

**GitHub Repository:** https://github.com/ArletteT3/Pin-Security-Simulator
