
# CyberGuard AI – Cybersecurity Assistant

## Project Overview

CyberGuard AI is an AI-assisted cybersecurity application designed
to help users understand security alerts, identify suspicious
activity, and learn basic security investigation techniques.

The application focuses on making cybersecurity information
easier to understand while introducing concepts used in
Security Operations Centers (SOC).

## Objectives

- Analyze common cybersecurity alerts.
- Explain suspicious login activity.
- Identify potential security risks.
- Recommend investigation steps.
- Provide understandable security explanations.

## Planned Technologies

- Python
- Streamlit
- Generative AI API
- Git and GitHub

## Intended Features

1. Security alert analysis
2. Suspicious activity explanations
3. Threat severity assessment
4. Recommended investigation steps
5. User-friendly interface

## Security Considerations

- API credentials will be stored securely and never committed.
- The application will not execute security commands.
- Analysis results are informational and require human verification.
- No real passwords or sensitive information should be submitted.

## Development Process

This project is being developed with AI-assisted programming.
Prompts, implementation decisions, testing, and improvements
will be documented as part of the Senior Seminar assignment.
